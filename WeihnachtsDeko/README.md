# 🎄 WeihnachtsDeko

Weihnachtliche Deko und Möbel für den Winterserver. Gekauft wird mit **Smaragden**.

## ✨ Features

- `/deko` öffnet den Deko-Shop
- `/moebel` öffnet den Möbel-Shop
- Bezahlung mit Smaragden
- Admins können Händler setzen, Deko verschenken und fremde Deko abbauen

<!-- Screenshot: ../docs/screenshots/deko-menue.png -->

## 📜 Befehle

| Befehl | Beschreibung | Permission |
|---|---|---|
| `/deko` | Deko-Shop | `deko.use` |
| `/moebel` | Möbel-Shop | `moebel.use` |
| – | Möbel platzieren | `moebel.platzieren` |

Die Admin-Befehle findest du in der [PERMISSIONS.md](../PERMISSIONS.md#-wintermarkt---weihnachtsdeko---wintermonitor).
