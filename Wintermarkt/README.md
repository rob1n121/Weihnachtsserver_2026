# 🏪 Wintermarkt

**Version 1.1.0** · Der Wintermarkt mit dem Händler **Eberwin**.

## ✨ Features

- Der Markt öffnet sich mit `/markt` oder `/wintermarkt`, wenn Eberwin in der Nähe ist.
- Alternativ: Schleichen und Rechtsklick auf Eberwin

<!-- Screenshot: ../docs/screenshots/wintermarkt.png -->

## 📜 Befehle

| Befehl | Beschreibung | Permission |
|---|---|---|
| `/markt` · `/wintermarkt` | Wintermarkt öffnen | `wintermarkt.use` |
| `/markt reload` | Config neu laden | `wintermarkt.admin` |
